# STM32C8T6 智能手表

> 基于 STM32F103C8T6 的智能手表小项目，OLED 显示 + 六轴姿态感应 + 滑动菜单交互。

| 项目 | 说明 |
| :--- | :--- |
| 主控芯片 | STM32F103C8T6 |
| 开发环境 | Keil MDK5（标准外设库 SPL） |
| 显示 | OLED 显示屏 |
| 传感器 | MPU6050 六轴姿态模块 |
| 完成日期 | 2026-11-07 |

---

## ✨ 已实现功能

| # | 功能 | 说明 |
| :-: | :--- | :--- |
| 1 | 🔦 手电筒 | 一键点亮照明 |
| 2 | 🖥️ OLED 显示 | 显示时间、菜单与状态信息 |
| 3 | 📐 MPU6050 模块 | 六轴加速度 / 角速度姿态检测 |
| 4 | 📜 滑动菜单界面 | 上下滑动切换功能页面 |

## 📁 目录结构

```
1-4mpu6050/
├── Hardware/              # 外设驱动
│   ├── OLED.c / .h        # OLED 显示驱动
│   ├── MPU6050.c / .h     # 六轴传感器驱动
│   ├── Light.c / .h       # 手电筒
│   ├── menu.c / .h        # 滑动菜单
│   ├── setTime.c / .h     # 时间设置
│   └── SecTimer.c / .h    # 秒表 / 定时
├── my_lib/                # 基础库与字体资源
├── startup/               # 启动文件
├── std_periph_driver/     # STM32 标准外设库
└── user/                  # main.c、中断与系统配置
```

---

## 🛠️ 编译与烧录

1. 用 Keil MDK5 打开 `1-4mpu6050/1-4mpu6050.uvprojx`
2. `Rebuild` 全编译
3. 用 ST-Link 烧录到开发板
